The Solution

HOW APRIL GATE WORKS

// 01
HARDWARE SIGNING

Each sensor is backed by a secure element chip. Every reading is signed with a private key that never leaves the hardware — making forgery physically impossible.

// 02
MESH CONSENSUS

Multiple sensors form a local network and reach cryptographic consensus on readings — even with no internet connection. A single rogue sensor cannot corrupt the record.

// 03
ON-CHAIN PROOF CHAIN

Each reading is committed to a hash chain anchored on Solana — every entry links to the one before it. Altering or removing any record breaks the chain and is immediately detectable. Only a compact commitment goes on-chain; raw operational data stays encrypted off-chain.

// 04
ON-CHAIN TRUTH

The proof is submitted to Solana on reconnection. Nobody — not us, not the shipper, not anyone — can alter it afterward. One immutable record. Verifiable by all parties instantly.
